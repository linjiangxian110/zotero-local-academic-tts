# Changelog

## v0.1.20

MVP release.

- Added Zotero Preferences integration for backend URL, voice, speed, and debug menu visibility.
- Added Kokoro-backed local TTS synthesis.
- Added selected-text reading from Zotero PDF Reader.
- Added long text chunking and sequential playback.
- Added floating Reader pause/resume control.
- Kept `Tools -> Local TTS -> Stop` as a backup stop control.
- Added diagnostic fake provider and backend tests.
- Added Windows Kokoro startup script with health checks.
- Added Chinese usage guide and release test checklist.
